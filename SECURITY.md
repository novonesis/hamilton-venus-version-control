# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for a security vulnerability.

Report it privately through
[GitHub private vulnerability reporting](https://github.com/novozymes-digital/hamilton-venus-version-control/security/advisories/new),
or contact the maintainer named in [CODEOWNERS](CODEOWNERS).

You can expect an acknowledgement within five working days and an assessment
of severity and remediation plan within ten working days.

## Supported versions

The most recent release on the `main` branch is supported. Older versions do
not receive security fixes.

## Scope

This policy covers **Hamilton Method Versionator**: Git-based version control for Hamilton liquid-handling robot methods. Reports
about the project's own code, dependencies, and build pipeline are in scope.

## Handling of sensitive material

If you believe this repository has published credentials, internal
infrastructure details, or other material that should not be public, say so
in your report and we will treat it as an incident: the repository is made
private immediately, any exposed credentials are rotated whether or not they
were used, and the history is cleaned before republication.
